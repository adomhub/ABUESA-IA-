# Demande CLDR — ikposso (kpo)

But : faire entrer l'ikposso dans CLDR (Unicode), la base qui fournit jours, mois et dates aux téléphones et ordinateurs.

## Étapes
1. Données de base (« Core Data ») via le formulaire officiel CLDR :
   - code langue : `kpo` (ISO 639-3), écriture latine, région par défaut Togo (`kpo_Latn_TG`)
   - jeux de caractères (principal, auxiliaire, chiffres, ponctuation) — à valider par Alexi
   - pays et nombre de locuteurs (Togo, Ghana)
   - format horaire : 24 h (H), comme au Togo
2. Compte « Survey Tool » pour Alexi.
3. Au cycle suivant : niveau « Basic » (jours, mois, hier/aujourd'hui/demain, noms de langues et pays, etc.).
